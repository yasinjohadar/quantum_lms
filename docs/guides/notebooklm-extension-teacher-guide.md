# دليل المعلم: استيراد أسئلة NotebookLM إلى كوانتم

## المتطلبات

- حساب على منصة كوانتم بصلاحية **استيراد الأسئلة** (`question-import`).
- دور: أدمن، معلم، أو مشرف.
- متصفح Google Chrome.
- تثبيت إضافة `chrome-extension` من المجلد (وضع المطوّر) أو من المتجر لاحقاً.

## خطوات الاستخدام

1. **ضبط البيئة**  
   في نافذة الإضافة اختر: محلي / تجريبي / إنتاج. يمكن تخصيص عناوين API من صفحة إعدادات الإضافة.

2. **تسجيل الدخول**  
   أدخل البريد وكلمة المرور نفس حساب لوحة التحكم. لا تُخزَّن كلمة المرور — يُحفظ رمز API فقط.

3. **إنشاء الاختبار في NotebookLM**  
   افتح [NotebookLM](https://notebooklm.google.com/) وأنشئ Quiz في Studio.

4. **فتح بطاقة الاختبار (مهم)**  
   انقر على بطاقة الـ Quiz في لوحة Studio حتى تظهر الأسئلة (مثل `Question 1 of 10`) على اليمين.

5. **استخراج الأسئلة**  
   من نفس التبويب، افتح الإضافة واضغط **استخراج من الصفحة**. الإصدار 1.2+ يقرأ بيانات `app-root` من iframe Google تلقائياً.

6. **اختيار المادة**  
   اختر الصف (اختياري)، المادة، والوحدة إن رغبت.

7. **الحفظ**  
   اضغط **حفظ في بنك الأسئلة**. ستظهر رسالة بعدد الأسئلة المحفوظة أو المعطّلة.

## إذا فشل الاستخراج التلقائي

1. صدّر الأسئلة بصيغة JSON (أداة متوافقة مثل NotebookLM Quiz Exporter).
2. في الإضافة: **لصق JSON** → الصق المحتوى → **تحميل من JSON**.
3. أكمل الخطوات 5–6 أعلاه.

## صيغة JSON المدعومة

```json
{
  "questions": [
    {
      "title": "نص السؤال",
      "type": "single_choice",
      "options": [
        {"text": "الخيار 1", "is_correct": true},
        {"text": "الخيار 2", "is_correct": false}
      ],
      "explanation": "شرح اختياري"
    }
  ]
}
```

الأنواع المفضّلة في المرحلة الأولى: `single_choice`, `multiple_choice`, `true_false`.

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| «لم يُعثر على أسئلة» | انقر بطاقة Quiz في Studio حتى تظهر الأسئلة؛ Reload الإضافة (v1.2+) |
| «افتح صفحة Quiz» | تأكد أن التبويب على `notebooklm.google.com` |
| 403 عند الدخول | تحقق من الصلاحية والدور |
| 0 أسئلة مستخرجة | استخدم لصق JSON |
| عنوان API خاطئ | حدّث البيئة في الإعدادات |
